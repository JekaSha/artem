SQL — говорим с базой данных

База — как тетрадь с таблицами. SQL — команды, с помощью которых мы читаем и меняем записи. В нашей базе две таблицы: users — пользователи и scores — их очки в играх.

Таблица users — пользователи

Одна строка — один пользователь.

СтолбецТипЧто хранит
loginTEXT PRIMARY KEYЛогин. PRIMARY KEY значит «не повторяется»: двух artem быть не может.
passwordTEXT NOT NULLПароль. NOT NULL значит «нельзя оставить пустым».
nameTEXT NOT NULLИмя, которое видно в профиле.
aboutTEXT NOT NULL DEFAULT ''Описание. DEFAULT '' значит «если не написали — пустая строка».

Таблица scores — очки в играх

Одна строка — одна сыгранная игра.

СтолбецТипЧто хранит
idINTEGER PRIMARY KEYНомер записи. База сама выдаёт следующий номер.
loginTEXT NOT NULL REFERENCES users(login)Чья это игра. Тут пишем login из таблицы users.
gameTEXT NOT NULLНазвание игры.
pointsINTEGER NOT NULLСколько очков набрано. INTEGER — целое число.

Как таблицы соединяются

  users                    scores
  ─────────                ─────────
  login  ───── один ко ──→ login
  password       многим    id
  name                     game
  about                    points

В users логин artem есть один раз. В scores логин artem встречается много раз — у Артёма много игр.

В scores мы не пишем имя «Артём», только логин artem. Чтобы увидеть имя рядом с очками, соединяем таблицы через JOIN:

SELECT scores.id, scores.login, users.name, scores.game, scores.points
FROM scores
JOIN users ON users.login = scores.login

ON users.login = scores.login значит: к каждой строке из scores приклей строку из users с таким же логином. scores.login значит «столбец login из таблицы scores».

Попробуй свой запрос

Пиши один запрос за раз. Добавление и удаление сразу сохраняются в настоящей базе users.db. Таблицы выше обновятся, когда ты обновишь страницу.

Шпаргалка

Скопируй пример в поле сверху и нажми «Выполнить».

Получать — SELECT

«Покажи всех пользователей». Звёздочка означает «все столбцы».

SELECT * FROM users;

Добавлять — INSERT

«Добавь Машу». В скобках — названия столбцов, после VALUES — что в них записать. Логин должен быть новым.

INSERT INTO users (login, password, name, about)
VALUES ('masha', '1234', 'Маша', 'Люблю рисовать.');

Удалять — DELETE

«Удали пользователя с логином masha». WHERE значит «только тех, у кого…». Без WHERE удалятся все пользователи.

DELETE FROM users
WHERE login = 'masha';

Считать — COUNT

«Сколько всего пользователей?» COUNT(*) считает строки, а AS total даёт имя столбцу с ответом.

SELECT COUNT(*) AS total FROM users;

Добавить очки

«Кирилл набрал 150 очков в Змейке». id не пишем — база выдаст номер сама.

INSERT INTO scores (login, game, points)
VALUES ('kirill', 'Змейка', 150);

Соединять — JOIN

«Покажи имя, игру и очки». Имя берём из users, игру и очки — из scores.

SELECT users.name, scores.game, scores.points
FROM scores
JOIN users ON users.login = scores.login;

Сумма очков — GROUP BY

GROUP BY собирает игры одного игрока вместе, SUM складывает его очки.

SELECT users.name, SUM(scores.points) AS total
FROM scores
JOIN users ON users.login = scores.login
GROUP BY users.name;

Очки одного игрока — WHERE

«Покажи все игры Артёма».

SELECT users.name, scores.game, scores.points
FROM scores
JOIN users ON users.login = scores.login
WHERE users.login = 'artem';

Текст пишем в одинарных кавычках: 'Маша'. Числа — без кавычек: 150.
