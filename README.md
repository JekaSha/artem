# Простой вход в профиль

Слева — форма на Vue, справа — редактор настоящего кода. Урок 1 проверяет логин и пароль и показывает имя, логин и описание пользователя. Урок 2 ищет пользователей по части логина. Урок 3 позволяет вставить INSERT через SQL-инъекцию в поле поиска.

После нажатия «Войти» под формой появляется выполненный SQL-запрос с введёнными значениями и подсветкой синтаксиса. Это та же строка, которую Python передаёт в `database.execute(query)`.

В обоих уроках SQL-запрос также виден во время ввода. После отправки формы показывается строка запроса из ответа Python. Если изменить обработчик в редакторе, предварительный запрос во Vue нужно изменить отдельно.

В блоке «Сам SQL-запрос» строка выводится через `v-text` полностью, включая буквальные HTML-теги. В уроке 1 ниже остаётся дополнительный блок «Вывод этого запроса через v-html», где эти теги становятся HTML-элементами.

В уроке 2 подпись «Ваш запрос:» показывает именно введённое слово поиска через `<span v-html="word"></span>`. Сформированный SQL выводится отдельно, в блоке «Сам SQL-запрос», как обычный текст.

Поиском можно поделиться ссылкой: http://127.0.0.1:8000/lessons/2?word=kir. При открытии слово берётся из параметра `word`, подставляется в форму, и поиск выполняется автоматически. Ссылка на текущий поиск показана под формой и сохраняется в адресной строке после нажатия «Найти». Vue отправляет запрос к Python по адресу `/search?word=kir`; этот адрес возвращает JSON с результатами. Параметры кодируются через `URLSearchParams`, поэтому кавычки, HTML, `&` и другие символы передаются как часть слова.

Например, введённое `<a href="https://google.com">google.com</a>` под подписью «Ваш запрос:» отобразится настоящей ссылкой. Это намеренно небезопасный учебный пример прямого HTML-вывода (XSS).

В верхнем меню есть «Уроки», «Урок 1», «Урок 2», «Урок 3» и «SQL». На странице http://127.0.0.1:8000/lessons показаны все 5 уроков. Уроки 1–3 работают, страницы уроков 4–5 подготовлены для будущего содержания.

Раздел «SQL»: http://127.0.0.1:8000/sql. При открытии он показывает все столбцы и строки таблицы `users`, включая открытые пароли. В поле можно написать один SQL-запрос и нажать «Выполнить». Результаты чтения появятся в таблице; добавление и удаление сразу сохраняются в `users.db`. Кнопка «Показать таблицу users» перечитывает всех пользователей. Ниже есть короткие объяснения и примеры SELECT, INSERT, DELETE и COUNT.

## Как запустить

Открой терминал в папке проекта и выполни команды по очереди:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Открой в браузере http://127.0.0.1:8000.

Используем порт 8000, потому что на Mac порт 5000 может быть занят AirPlay и возвращать ошибку 403.

Введи логин `artem` и пароль `1234`. Увидишь: «Привет, Артём! Это твой профиль.»

Второй пользователь: логин `kirill`, пароль `1234`. Увидишь: «Привет, Кирилл! Это твой профиль.»

Чтобы остановить программу, нажми Ctrl+C в терминале.

## Как редактировать код на странице

Справа в уроках 1–3 есть вкладки «Бэкенд — Python» и «Vue».

1. Выбери вкладку и измени код в редакторе.
2. Нажми «Проверить синтаксис». Для Python проверяется синтаксис файла и наличие функции `handle(database_path)`. Для Vue проверяется синтаксис JavaScript через `node --check`.
3. Нажми «Сохранить». Код ещё раз проверяется и записывается в файл на диске. Код с синтаксической ошибкой не сохраняется.

Python из `handlers/lesson1.py`, `handlers/lesson2.py` или `handlers/lesson3.py` читается заново при каждой отправке формы. Перезапускать сервер после сохранения обработчика не нужно.

Vue сохраняется в `static/lesson1.js`, `static/lesson2.js` или `static/lesson3.js`. После сохранения страница обновляется и загружает новый файл. Несохранённые черновики вкладок остаются в текущей вкладке браузера при переключении и обновлении страницы.

Для проверки JavaScript нужен установленный Node.js. Сборка фронтенда не нужна. Проверка синтаксиса не гарантирует отсутствие ошибок в логике программы; ошибки выполнения обработчика показываются под формой.

## Где что находится

- `templates/index.html` — меню и две колонки страницы урока.
- `templates/editor.html` и `static/editor.js` — редактор, переключение вкладок, проверка и сохранение файлов.
- `handlers/lesson1.py` — обработчик входа: логин, пароль, имя и описание.
- `handlers/lesson2.py` — обработчик поиска по логину.
- `handlers/lesson3.py` — учебный обработчик SQL-инъекции с `executescript`.
- `static/lesson1.js`, `static/lesson2.js`, `static/lesson3.js` — Vue-формы и отправка данных в Python.
- `app.py` — запуск приложения, создание и обновление базы, маршруты, проверка и запись кода.
- `static/vue.global.prod.js` — библиотека Vue. Она лежит локально, поэтому для работы страницы интернет не нужен.
- `static/codemirror/` — редактор с подсветкой Python и JavaScript.
- `static/highlight.min.js` и `static/highlight-github-dark.min.css` — подсветка SQL-запросов.
- `users.db` — файл базы. Создаётся автоматически при первом запуске.

Таблица `users` содержит поля `login`, `password`, `name`, `about`. Поле `about` — описание пользователя. Оно добавляется в старую базу автоматически, без удаления записей. В разделе SQL можно изменить описание, например:

```sql
UPDATE users SET about = 'Люблю Python и игры.' WHERE login = 'kirill';
```

## Как работает запрос

```python
f"SELECT login, name, about FROM users WHERE login = '{login}' AND password = '{password}'"
```

Это значит: «Найди имя пользователя, у которого совпадают логин и пароль». Python подставляет значения переменных вместо `{login}` и `{password}`. Одинарные кавычки обозначают текст в SQL. Для учебного пользователя получится:

```sql
SELECT login, name, about FROM users WHERE login = 'artem' AND password = '1234'
```

Такой вариант оставлен по твоей просьбе для обучения. Он уязвим к SQL-инъекциям: введённые кавычки могут изменить смысл запроса или вызвать ошибку. Для настоящего приложения используй `?` и отдельные параметры.

Если пользователь найден, `user[0]` содержит логин, `user[1]` — имя, `user[2]` — описание. Если нет — показываем сообщение об ошибке.

В уроке 2 ввод `kir` создаёт запрос:

```sql
SELECT login, name, about FROM users WHERE login LIKE '%kir%'
```

`LIKE` ищет похожий текст, а `%` означает любое количество символов. Поэтому `kir` найдёт `kirill`. Под формой показываются точный запрос и его результат, в том числе когда ничего не найдено или произошла ошибка SQL.

## Урок 3: INSERT через SQL-инъекцию

Открой http://127.0.0.1:8000/lessons/3. Нажми «Подставить INSERT», а затем «Выполнить». В поле появится:

```sql
'; INSERT INTO users (login, password, name, about) VALUES ('lesson3_user', '1234', 'Ученик', 'Добавлен через SQL-инъекцию.'); --
```

Кавычка закрывает строку поиска. `;` завершает SELECT. INSERT добавляет пользователя, а `--` комментирует оставшийся хвост запроса. После выполнения показывается вся таблица users, включая добавленную запись. Изменения сохраняются в настоящем `users.db`. При повторном запуске примера поменяй `lesson3_user` на новый логин.

В `handlers/lesson3.py` намеренно используется `database.executescript(query)`, который допускает несколько SQL-команд. В уроке 2 `database.execute(query)` допускает одну команду, поэтому такой INSERT там не выполнится. В уроке 3 SELECT из скрипта не возвращает результаты в интерфейс: таблица пользователей перечитывается отдельным SELECT после выполнения скрипта.

В HTML `v-model="login"` и `v-model="password"` сохраняют введённые значения в переменные Vue. `@submit.prevent="signIn"` запускает функцию отправки вместо перезагрузки страницы. `fetch('/login', ...)` передаёт данные Python, а `v-text="message"` показывает его ответ под формой.

Пример подключения Vue без сборки описан в [официальной документации](https://vuejs.org/guide/quick-start.html#using-vue-from-cdn). Файл библиотеки сохранён с https://unpkg.com/vue@3/dist/vue.global.prod.js; его версия указана в начале файла.

Для подсветки используется [highlight.js](https://highlightjs.org/) 11.12.0. Библиотека и тема тоже лежат локально; лицензия — в `static/highlight-LICENSE`.

Для редактирования используется CodeMirror 5.65.20. Файлы библиотеки и лицензия лежат в `static/codemirror/`.

По твоей просьбе пароль виден в поле ввода и хранится в базе открытым текстом. Это учебный пример для своего компьютера; в настоящем приложении нужно хранить хеш пароля.
